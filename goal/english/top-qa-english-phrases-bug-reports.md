## Top QA English Phrases for Bug Reports (Real Examples)

### Bug Description

**The issue occurs when...**  
✔ Used to describe the condition under which the bug appears

Example:
```text
The issue occurs when the user submits the form without filling in required fields.

**An error message is displayed...**
✔ Used to describe visible UI errors

Example:
```text
An error message is displayed after clicking the Submit button.

**The application crashes when...**
✔ Used for critical issues

Example:
```text
The application crashes when the user opens the Settings page.

### Steps & Reproduction

**Steps to reproduce:**
✔ Standard phrase in all bug reports

Example:
```text
1. Open the application
2. Navigate to the Profile page
3. Click the Save button

**The issue is reproducible...**
✔ Indicates consistency of the bug

Example:
```text
The issue is reproducible on every attempt.

**The issue occurs intermittently**
✔ Used when the bug does not occur every time

Example:
```text
The issue occurs intermittently during form submission.

### Actual Result

**Actual result:**
✔ Describes what actually happens

Example:
```text
Actual result: The page reloads and entered data is lost.

**No response is observed**
✔ Used when UI does not react

Example:
```text
No response is observed after clicking the Submit button.

### Expected Result

** Expected Result**
✔ Describes correct system behavior

Example:
```text
Expected result: The data should be saved successfully.

**The user should be redirected to...**
✔ The user should be redirected to...

Example:
```text
The user should be redirected to the confirmation page.

### Environment & Scope

**The issue occurs in the following environment:**
✔ Used to specify test environment

Example:
```text
The issue occurs in the following environment: iOS 17, Safari browser.

**The issue is not reproducible on...**
✔ Used for environment comparison

Example:
```text
The issue is not reproducible on Android devices.

### Severity & Priority

**Severity: High**
✔ Used when main functionality is blocked

Example:
```text
Severity: High — blocks checkout functionality.

**Priority: Medium**
✔ Used to define urgency

Example:
```text
Priority: Medium — workaround is available.

### Additional Information

**Screenshot / video attached**
✔ Confirms supporting evidence

Example:
```text
Screenshot attached for reference.

**Please see logs below**
✔ Used for technical details

Example:
```text
Please see console logs below.
