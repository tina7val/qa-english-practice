## QA English Phrases & Mini Dictionary

### 🔹 Common QA Terms

**Test case**  
✔ A set of conditions and steps to verify a specific feature

**Bug report**  
✔ A document describing a defect found during testing

**Preconditions**  
✔ Conditions that must be met before test execution

**Steps to reproduce**  
✔ Clear instructions to reproduce an issue

**Actual result**  
✔ The behavior observed during testing

**Expected result**  
✔ The correct behavior according to requirements

**Severity**  
✔ Indicates how serious the bug is

**Priority**  
✔ Indicates how urgently the bug should be fixed

**Status**  
✔ Current state of the test case or bug (e.g. Open, In Progress, Fixed)

---

### 🔹 Useful QA Sentences

**The issue occurs when...**  
✔ Used to describe the condition under which a bug appears

**User is redirected to...**  
✔ Describes navigation behavior

**Validation message is displayed**  
✔ Used when checking form validations

**The button is not responsive**  
✔ Indicates that the button does not react to user interaction

**The field accepts invalid input**  
✔ Used when input validation does not work correctly

---

### 🔹 Severity Levels

**Low** — cosmetic issue, does not affect functionality  
**Medium** — affects usability but has a workaround  
**High** — blocks main functionality  
**Critical** — system does not work / application crash

---

### 💡 QA Note

- Use clear and simple sentences in bug reports
- Avoid emotional language, focus on facts
- Consistent terminology improves communication with developers
